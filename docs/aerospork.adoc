== Synopsis
[verse]
aerospork [-h|--help] [-v|--version] <subcommand> [<subcommand-options>...] [<subcommand-arguments>...]

== Description

AeroSpork is an i3-like tiling window manager for macOS.

The *aerospork* command line program manipulates AeroSpork and queries its state.

See https://aerospork.app/docs/commands.html for the available <subcommand> options

See each subcommand's own man page for its <subcommand-options> and <subcommand-arguments>

== Options

-h, --help:: Print help

-v, --version:: Print the version
