== Description

// tag::body[]
{manpurpose}

Equivalent to choosing *Settings…* from the menu bar icon, or pressing kbd:[Cmd+,] while
AeroSpork is frontmost. The settings window is a singleton: running this while it is already open
brings the existing window to the front.

The command is allowed in config, so it can be bound to a key:

[source,toml]
----
[mode.main.binding]
alt-shift-comma = 'open-settings'
----

Structured settings apply live as you change them. The *Raw TOML* pane is the exception: it applies
explicitly, so half-typed TOML is never written. The window remembers its selected pane. Raw TOML
supports native Find, line numbers, section jumps, and parser errors that link to the failing line.
