The product's most recognizable mark after the app icon. Use in menu-bar mocks, marketing shots and docs.

~~~jsx
<WorkspaceChips ink="light" items={[
  { name: '1', active: true }, { name: '2' }, { name: 'web' },
  { name: 'service', type: 'mode', active: true },
]} />
~~~

Rounded (SF Pro Rounded) semibold glyphs, monochrome only — never tint a chip. Show only workspaces that are actually visible on a monitor, plus the active mode.
